# Molosoc — Design Direction

## Purpose
This document defines the permanent visual direction for the Molosoc website.
Every AI agent working on this project must follow these principles.
This is not optional guidance — this is the visual standard of the brand.

## Scope of this rebuild
This is **not** a redesign of the current website's visual layer.
Treat the existing Molosoc website only as the **source of truth** for:
- brand
- messaging
- products
- colors
- typography
- content

The visual presentation should be **completely reimagined**. The goal is an expensive,
premium wellness brand experience — not an incremental update.

---

## Brand Personality
Molosoc is **not** a medical device company.
Molosoc is **not** a discount ecommerce store.
Molosoc is **not** a generic WooCommerce website.

Molosoc is a premium wellness brand focused on healthy feet, self-care, comfort, and confidence.

The website should immediately communicate:
- calm
- premium
- trust
- simplicity
- wellness
- cleanliness
- softness
- confidence

Visitors should think: **"This feels like a luxury skincare brand."**
Not: "This looks like another ecommerce template."

---

## Design Philosophy
Closer to:
- Apple
- Aesop
- Minimal Scandinavian design
- Luxury wellness / spa atmosphere
- Premium skincare
- Editorial magazine

Not:
- Amazon
- Generic Shopify/WooCommerce themes
- Corporate websites
- Medical websites
- Generic AI-website look
- Block-stacked sections

---

## Visual Hierarchy
- Every section must have a clear purpose.
- Each screen should communicate **one** primary idea.
- Avoid visual noise.
- Large margins, generous whitespace.
- Strong typography, minimal UI.
- Never overwhelm the visitor.

---

## Storytelling
The homepage is not a product catalog — it is a guided story.

**Order:**
1. Emotional opening
2. The problem
3. Why current solutions fail
4. How Molosoc works
5. Benefits
6. Social proof
7. Product
8. Educational content
9. Final CTA

Educate first. Sell second.

---

## Layout
The website should feel immersive. Avoid stacked blocks. Instead use:
- full viewport sections
- visual depth
- cinematic composition
- premium spacing

Each section should feel like **entering another room** — pinned scrolling, elegant fade
transitions, layered imagery, depth — rather than moving through stacked blocks.

---

## Typography
Typography carries the luxury feeling. Requirements:
- Elegant, editorial, high contrast, readable, sophisticated
- Avoid generic AI typography (no Inter unless there is a compelling reason)
- Avoid visual clutter
- Never use a typeface simply because it's popular
- Create clear visual hierarchy

---

## Color Palette
Use existing Molosoc branding. Colors should feel:
- soft, warm, natural, minimal, restrained

Never use highly saturated colors. Never create visual chaos. Whitespace is part of the design.

---

## Photography
Photography is the hero.
- Images should breathe — don't crowd them with text.
- Lifestyle images create emotion.
- Isolated product cutouts explain features/benefits.
- Give product photography space; the product must always remain the hero.

**Always respect the mappings inside `assets/molosoc-image-assets.csv`.**
Never randomly assign or place imagery.

---

## WooCommerce
WooCommerce must disappear visually. Visitors should not feel like they entered a store.
They should feel like they entered a premium brand experience. The commerce layer should
feel invisible.

---

## Mobile
Mobile is equally important as desktop.
- Do not simply stack desktop sections onto a smaller screen — design specifically for touch interaction.
- Comfortable spacing, readable typography, fast loading, premium experience.
- The mobile version should feel intentionally designed, not a shrunk desktop layout.

---

## Accessibility
- High contrast
- Keyboard navigation
- Proper headings
- Alt text
- Readable font sizes
- Accessible animations (respect `prefers-reduced-motion`)

---

## Final Goal
The finished website should feel expensive — not because of decoration, but because of
restraint. Every element must have intention.
